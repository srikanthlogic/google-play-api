v2 Roadmap

All v2 work integrates through the v2dev coordinating branch. Individual features merge to v2dev; milestones are tracked as GitHub issues.

M0 — Foundation & Deployment current

Implemented: v2 routing and RFC 9457 problem responses. v1 remains available during the documented sunset window.

  • v2dev coordinating branch + contribution flow
  • gplayapiv2 Fly.io verification deployment (no throttling)
  • /docs documentation microsite shipped in the Docker image
  • API versioning: v2 under /v2/ prefix, v1 frozen with Sunset header
  • RFC 9457 standardized error shape
  • OpenAPI 3.1 generated from zod schemas (drop Postman-generated spec)
  • Response schema validation at the API boundary
  • npm audit debt cleanup (body-parser, lodash via newman, jose)
  • Country/lang defaults consistency fix

M1 — New Endpoints

  • Batch app details endpoint
  • Country availability endpoint
  • Promote suggest to GET /api/suggest
  • Field selection / sparse responses (?fields=)
  • List pagination via iterators; honest 200-cap
  • Streaming/bulk reviews export (NDJSON/CSV)
  • Search/developer iterators exposed (cursor pagination)

M2 — Reliability

  • Response cache with per-endpoint TTLs
  • Request coalescing
  • Circuit breaker / stale-on-error degradation
  • Upstream health probe / drift alerting
  • Retry/backoff at API layer
  • Request timeout budget
  • ETag / conditional requests

Later — M3/M4/M5

Auth & credits (API keys, credit ledger, per-key quotas, usage dashboard), monetization (Stripe credit packs, admin surface, status page), DX & growth (TypeScript/Python SDKs, watch webhooks). Tracked in the deficiency log.
