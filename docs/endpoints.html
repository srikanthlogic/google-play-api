API Endpoints

Base path: /api/ (frozen v1) or /v2/ (current). JSON responses. Interactive reference at /api-docs (Swagger UI) and /openapi.json.

Versioning: v2 is available under /v2/. The frozen v1 surface remains under /api/ and returns Deprecation and Sunset headers. The two surfaces share paths — pick the prefix.

Common query parameters

ParamApplies toNotes
lang all ISO 639-1. Default en. Lowercased. Invalid → 400 on v2.
country all ISO 3166-1 alpha-2. Default US (or COUNTRY_OF_QUERY). Uppercased. Invalid → 400 on v2.
num list endpoints 1–200. Default 20.
fullDetail GET /api/apps Enrich search results with full app detail (slower).
fields GET /api/apps/:appId Comma-separated projection, e.g. ?fields=title,score,installs. Unknown fields → 400 with the full whitelist. Field selection is not data minimization — the server still fetches the full upstream payload.
sort GET /api/apps/:appId/reviews newest | rating | helpfulness.

Examples

curl "https://gplayapiv2.fly.dev/api/apps/com.phonepe.app?country=IN"
curl "https://gplayapiv2.fly.dev/api/apps?q=upi&num=5"
curl "https://gplayapiv2.fly.dev/api/lists?category=GAME&collection=TOP_FREE&num=10"
