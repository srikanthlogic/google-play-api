API Endpoints

Base path: /api/ · JSON responses · interactive reference at /api-docs (Swagger UI) and /openapi.json.

Versioning: v2 is available under /v2/. The frozen v1 surface remains under /api/ and returns Deprecation and Sunset headers.

Common query params

  • lang — language code, e.g. en (default en)
  • country — country code, e.g. IN, US (default from COUNTRY_OF_QUERY)
  • num — number of results (list endpoints, capped at 200)
  • fullDetail — fetch full app details in search results
  • fields — comma-separated projection for app details, e.g. ?fields=title,score,installs. Unknown fields return 400 with the full whitelist. Field-selection is not a data-minimization feature — the server still fetches the full upstream payload.

Example

curl "https://gplayapiv2.fly.dev/api/apps/com.phonepe.app?country=IN"
curl "https://gplayapiv2.fly.dev/api/apps?q=upi&num=5"
curl "https://gplayapiv2.fly.dev/api/lists?category=GAME&collection=TOP_FREE&num=10"
