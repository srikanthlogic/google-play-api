Deployment

The API ships as a Docker image (Node 22 Alpine, non-root user, dumb-init PID 1). The image includes this documentation microsite at /docs.

Instances

AppBranchPurpose
gplayapiv2v2devv2 verification (throttling disabled)
gplayapidevdevstaging (CI)
googleplayapimainproduction (CI)

Deploying from v2dev

flyctl deploy -c fly.v2dev.toml --remote-only

CI also deploys automatically on every push to v2dev (see .github/workflows/deploy-v2dev.yml), building and pushing the v2dev image to GHCR, then deploying it.

Health check

GET /healthz returns 200 {"status":"ok"}. The Docker HEALTHCHECK and Fly deployments use this endpoint.
