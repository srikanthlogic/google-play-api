Google Play Store data, as an API

REST wrapper around @mradex77/google-play-scraper. Search apps, fetch details, reviews, permissions, data safety, lists, categories and collections.

Quick start

curl https://gplayapiv2.fly.dev/api/apps/com.instagram.android

Returns app metadata for Instagram as JSON.

Interactive docs

Swagger UI at /api-docs, raw OpenAPI 3.1 spec at /openapi.json.

Health

GET /healthz returns {"status":"ok"}. Used by the Docker healthcheck and Fly probes.

Versioning: v2 lives under /v2/. The frozen v1 surface stays under /api/ and returns Deprecation + Sunset headers until its announced removal. See the roadmap for dates and errors for the v2 RFC 9457 problem shape.

Common options

ParamDefaultDescription
country US Storefront country (ISO 3166-1 alpha-2). Override via COUNTRY_OF_QUERY env. See localization.
lang en UI language (ISO 639-1, e.g. en, ta). Override via LANG_OF_QUERY env. See localization.
num 20 Results per page (list endpoints, max 200).
throttling disabled See throttling — v2 verification deployment ships with it disabled.

Examples

# Search apps
curl "https://gplayapiv2.fly.dev/api/apps?q=paytm&num=10"

# Reviews for an app (paginated)
curl "https://gplayapiv2.fly.dev/api/apps/com.phonepe.app/reviews"

# Permissions
curl "https://gplayapiv2.fly.dev/api/apps/com.phonepe.app/permissions"
